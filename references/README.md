# Reference materials

The [paper](../paper/manuscript.pdf) contains the claims, core methods, and important failures. These materials provide the complete supporting records.

1. [Figure and table map](FIGURE_TABLE_MAP.md): locate evidence for each manuscript item.
2. [Methods and identifiers](METHODS_AND_IDENTIFIERS.md): input extraction, seeds, definitions, and identifiers (Japanese).
3. [Data inventory](DATA.md): original observations and saved exploratory arrays.
4. [Reproducibility guide](../docs/REPRODUCIBILITY.md): offline verification, restoration, and acquisition entry points.
5. [Manifest](MANIFEST.json): SHA-256 and size for each repository file; paths are relative to the repository root.

Tables D–L retain 269 detailed tables. The separate archival `appendix_A.md`–`appendix_C.md` preserve earlier method summaries; their labels are not the current manuscript's Appendix A–C. Use the paper for the current short appendices.

Summaries and numerical reports are under [research/pc_geometry_rerun](../research/pc_geometry_rerun/README.md). Large coefficient/prediction arrays are restored from the release assets. Reported failures, negative values, inconclusive conditions, and original denominators have not been removed.
