# EXP-0002 v1 — 未使用記事への基底転用と、単純な説明を超える特徴予測

2026-10-20。P1結果を知った上で設計するP2。ユーザーの依頼は「レポートのサジェスト通りP2」「設計、事前登録、１セルコード書くところまで」。実験実行者はユーザー。agentは入力準備・実装・合成検査まで行い、新しいモデルforwardは行わない。ローカル凍結日時・入力・ソース・セルは `../p2_v1/release_manifest.json` とリリース証拠で固定する。外部レジストリではない。

## 1. 問いと、P1から引き継ぐ範囲

GPT-2で、訓練記事だけから決めたPCA方向は別記事でも位置と関連するか。また、上位8PCを使うと、位置・復号長・訓練内トークン頻度・状態ノルムからの予測を超えて、現在トークンsurprisalを予測できるか。同次元ランダム方向との比較も行う。

P1のH1反証・H2支持は変更しない。先頭1点への感度が分かったことを因果機構の同定とは呼ばない。P1の文章内PCAから、P2では**訓練記事をまとめて推定した共通基底**へ問いを変える。評価記事で中心・基底・成分順位・符号・予測式を再調整しない。

## 3. 全条件を先に定める

| 条件 | 訓練・評価で同じ規則を適用 |
| --- | --- |
| C0 | 全512点、そのまま |
| C1 | 元位置0を除く511点。**主要条件** |
| C4 | 全512点を各ベクトルのノルムで除す |

C0/C1/C4をすべて報告し、良かった条件だけ選ばない。C1は保存状態の除外であり入力削除介入ではない。C4はP1との接続のための副次条件。P1の高ノルム6点除外・ランダム点除外はP2では繰り返さず、今回のランダム対照は**方向**である。

各点・条件について訓練64記事を連結し、訓練全体の平均で中心化した共分散行列をfloat64で完全固有分解する。上位8方向・全固有値・訓練平均を保存。各PCは絶対最大要素が正の符号に固定する。評価時も訓練平均を引き、凍結基底へ射影する。評価記事ごとの平均引き直し・再PCAはしない。各記事のトークン数は条件内で等しいため、訓練記事は等重み。

点・条件ごとに20組のランダム8次元直交基底を生成する。標準正規乱数行列のreduced QR、符号を固定。seedは `sha256("20261022:{point}:{condition}:{repetition}")` の先頭16桁から得るPCG64整数。評価記事に合わせて再抽選しない。元の768次元空間で生成し、PCA部分空間の中では生成しない。

### 3.1 位置に関連する「1方向」の転用

訓練記事ごとに、各PCスコアと元位置の符号付きPearson rを計算する。PCごとの記事中央値を取り、**その絶対値が最大の1PC**を選ぶ。候補は訓練58記事以上で相関が定義できるPCに限る。候補なしは位置転用をNAとする。同値は低いPC番号。訓練中央値が正になる向きに符号を決め、評価記事へ固定する。評価時は符号を反転し直さず、負のrもそのまま記録する。

各ランダム8方向の組にも、同じ訓練選択・符号固定を適用する。20組から評価結果を見て最良の組を選ばず、各評価記事で20個の符号付きrを平均して対照値とする。

選択PCまたは20組のどれかで相関が定義できなければ、その記事のランダム優位差BはNAとする。定義できる組だけを選んで平均しない。選択PC単独のAは、当該PCの相関が定義できれば残す。

位置は特徴として既知なので、これは位置予測システムの実用性能や純粋な位置機構を示す検定ではない。共有方向の再現性を問う。

### 3.2 surprisalの追加予測

基礎説明変数Bを次に固定する。位置`p=t/511`、`p²`、`p³`、`log1p(t)/log(512)`、`log1p(個別復号文字数)`、`log1p(UTF-8 byte数)`、`−log((訓練token頻度+1)/(訓練総tokens+50257))`、`log1p(元状態ノルム)`。

頻度はP2訓練64記事の全512 tokenだけから数え、C0/C1/C4で共通。評価側の語数・頻度を使わない。ゼロ頻度はadd-oneで扱う。ノルムはC4でも変換前の値を用いる。

左文脈長は、この固定先頭区間・causalモデルでは元位置tと同じなので、独立の説明変数・識別された効果として数えない。位置の線形・3次多項式・対数項で傾向を表すが、すべての交絡を取り除けたとは主張しない。

次の22個の線形ridge予測器を訓練だけで当てはめる：Bだけ、B＋上位8PC、B＋ランダム8方向を20組。損失は平均二乗誤差＋`0.01 × 係数二乗和`、切片は罰しない。説明変数を訓練の平均・母標準偏差で標準化し、訓練で定数の列は0に固定する。目的変数の訓練平均を切片として保存。係数、中心、尺度、定数列を凍結。正則化係数・次元数のチューニングはしない。

数値上の定数列は訓練母標準偏差≤1e−12と定義する。評価側でその列に変動が出ても再度有効化しない。

surprisalが定義される位置1〜511だけを訓練・評価に使う。C0とC4でも先頭はNAなので予測評価の分母は511。基礎Bだけのモデルは条件間で同じ訓練行を使う。PCAの当てはめ対象点は条件に従う。

評価記事ごとに `ΔR² = (SSE_B − SSE_B+PC)/SST` を記録する。SSTはその評価記事のsurprisalの平均周り二乗和。負値を0に丸めない。ランダム方向との優位差は `(mean_r SSE_B+random − SSE_B+PC)/SST`。評価ラベルは採点にだけ使い、モデル選択には使わない。

### 3.3 事前指定した副次分析

各PCと位置・個別復号文字数・surprisal・ノルムの相関、転用後の方向別分散、全8PCの合計分散比を保存する。記事内のPearsonは記事平均を内部で引く統計だが、基底・予測器の再当てはめではない。C4のノルム相関は変換後ノルムが定数のためNA。

`log1p(復号文字数)`も同じridgeで予測し、基礎説明変数は位置4項・訓練頻度・元ノルムの6項だけとする。文字数そのものとbyte数はこの基礎モデルから除く。評価のΔR²等を記述するが、追加の確認的仮説にはしない。品詞・意味の独立性・因果機構・別モデル間の基底転用は対象外。

## 4. 固定する主要量と判断

**block06 / C1のみ**を主要判定とする。64評価記事について以下を算出する。

| 量 | 定義 | 実質的基準 |
| --- | --- | ---: |
| A | 訓練で選んだPCの符号固定済み位置rの、評価記事中央値 | 0.50 |
| B | 各評価記事の位置r_PC−20組の位置r_random平均、その中央値 | 0.10 |
| C | surprisalのΔR²（Bモデルに8PCを加えた改善）の記事中央値 | 0.02 |
| D | surprisalのランダム8方向平均に対する8PCの優位差、その中央値 | 0.01 |

64評価記事を単位に10,000回のpercentile bootstrap、PCG64 seed 20261023。各量の両側**98.75%区間**、端点0.05/8と1−0.05/8。4区間へのBonferroni配分で全体約95%を狙う。訓練標本は固定した条件付きの不確実性であり、訓練し直す際の変動は含まない。有限標本の厳密な被覆保証ではない。トークンや20ランダム組を独立記事として数えない。

**P2-H1：位置関連方向が別記事へ転用でき、訓練選択を揃えたランダム方向より強い。** A下限≥0.50かつB下限≥0.10なら支持。A上限<0.50またはB上限<0.10なら反証。それ以外は不確定。

**P2-H2：上位8PCは基礎変数を超えるsurprisal予測を持ち、同次元ランダム方向より有効。** C下限≥0.02かつD下限≥0.01なら支持。C上限<0.02またはD上限<0.01なら反証。それ以外は不確定。Cが正でもDが基準未達なら、この複合仮説は支持としない。

閾値は本計画の操作的な効果量基準で、先行研究由来の普遍的境界や検出力保証ではない。各構成量の結果も併記する。H1/H2を一つの成功率にまとめない。

訓練64記事と評価64記事の取得・処理完了前は科学判定をPENDINGとする。主要量の有効記事が58未満なら、その量に依存する仮説はデータ不足。低相関・負の改善・予想外の方向は除外しない。

## 5. 欠測・故障・実行順序

- 非有限の原状態・入力不一致・抽出点不一致・環境不一致・保存破損は運用故障として停止し、ZIPとログを保持。別記事へ置換しない。
- 訓練のゼロ総分散、上位8未満の数値rank（固有値>総分散×1e−12）、訓練C4でゼロノルムは点・条件の解析不能として理由を保存する。定数特徴・定数目的変数・評価SSTゼロ・評価C4ゼロノルムもNA理由を残し、科学的反証とは分ける。
- **訓練64記事取得→全基底・選択・予測器・頻度を当てはめ→原訓練COMMITを参照したfitを封印→評価64記事取得→固定変換で採点**の順。評価forwardの前にfitの全ハッシュを検査し、各評価記事にfit COMMITハッシュを記録する。
- 評価記事があるのにfit封印がない場合は再当てはめせず停止。封印済みfitは再利用し上書きしない。訓練の変更・異なるfitとの混在を拒否する。不完全なfit/評価出力は別attemptへ保持してから再開。
- 完了単位のハッシュを確認してスキップし、no-opで追加forward 0を確認。各32記事で累積checkpoint、64記事時点はfit封印後、128記事で数値検算後にFINALを作る。checkpointは数値検証前と明示。
- NumPyによる当てはめ・採点は別プロセス。最終監査で原訓練から平均/共分散/固有値/基底方程式とridge解を検証し、評価予測・全指標・bootstrapを再計算する。固有値近接時に別の基底へ勝手に置換せず、保存された基底の妥当性と使用の一貫性を検査する。
