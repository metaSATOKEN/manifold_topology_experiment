## 1. 実験の1行

GPT-2とWikiText-2の64記事について、同一forwardの隠れ状態から先頭点・高ノルム点・ランダム点の除外と単位ノルム化を行い、PC1のノルム相関と分散比の感度を文章単位で測る。

### 解析と比較

float64の中心化PCA。完全SVDで上位8基底・スコアと全固有値を保存し、総分散は全中心化要素の二乗和/(n−1)。R1はPC1 scoreと原ノルムのPearson相関の絶対値、V1は第1固有値/総分散。基底符号は絶対最大要素が正になるよう固定。定数時の相関はNA。固有値≤総分散×1e−12の成分は数値的に退化した軸として特徴相関をNAにし、有効rankを保存する。正の総分散がある限り、その理由でR1/V1を除外しない。

| 条件 | 処理 |
|---|---|
| C0 | 全512点 |
| C1 | 元位置0を除外して再PCA、511点 |
| C2 | C0の原ノルム上位ceil(512×0.01)=6点を除外して再PCA、506点。同値は元位置の小さい順 |
| C3 | C0から6点を無復元抽出して除外、20反復。記事・抽出点・反復に結び付けた固定seed。各反復のR1/V1と除外位置を保存 |
| C4 | 全512点を各ノルムで除して再PCA。R1は定義上NA。ゼロノルム時は解析不能理由を保存 |

C3はGram行列の完全固有分解でR1/V1を計算し、C0/1/2/4のSVDと合成データで照合する。C3の基底全配列は保存しないが、原観測と除外位置から全反復を再現できる。C0/1/2/4は平均・上位8基底・スコア・全固有値を保存する。除外後の位置は再番号付けしない。これはforward後の感度分析であり、入力削除の因果介入ではない。

追加の固定基底診断：C0のPC1基底にC1/C2の残存状態を射影し、R1とその方向の分散/残存総分散を記録する。再推定の主要結果に置き換えない。

PC1〜8と位置・復号文字長・surprisalの相関はC0/1/2/4で記録する。これは文章内の探索的記述。PC2〜8の交絡統制・別記事への基底転用・予測性能・品詞に関する確認的主張はP2の別カードとする。

### 推定・欠測・資源

- 標本数64は輸送量・記事単位の分布推定を両立する固定枠。検出力の保証ではない。結果による追加・早期終了はしない。
- 主要3量：A=`median(R1_C1)`、B=`median(R1_C1−R1_C0)`、D=`median(V1_C2−mean_r(V1_C3r))`。C3の20反復を20記事とは数えない。
- 記事を単位に10,000回のpercentile bootstrap、PCG64 seed 20261021。各量の両側98.333333%区間（端点α=0.05/6）、量ごとに同じresample seedを使う。3区間へのBonferroni配分で近似的に全体95%を狙う。有限標本での厳密な被覆保証はない。主要層以外はこの判定に混ぜない。
- 完全64記事を試行し、各主要量は必要条件が数値的に定義できる記事のみを用いる。58記事未満ならその量と依存する仮説は「データ不足」。分母64、完了、解析可能、NA理由を並記する。低相関・低寄与率・境界未達を除外しない。
- rank不足、ゼロ総分散、定数特徴、ゼロノルムを明示して保存。非有限の原状態・抽出点不一致・保存不良・環境不一致・OOM等は運用故障で停止し、ログを保持して別記事へ置換しない。再試行時に既存COMMITを検証し成功分をスキップする。科学的判定は予定64記事の取得・解析処理が完了してから。
- Colab単一GPU、A100またはRTX PRO 6000 Blackwell。機種名・VRAM・ホストRAMを実測記録。Python 3.11〜3.13 / Torch 2.8.0+cu128 / Transformers 4.57.6 / NumPy 2.2.6等、全主要依存はspec固定。
- 1セルの処理枠120分（準備最大20分を含む）＋障害時ZIP回収最大5分。上限到達で停止・途中ZIPを作る。追加枠は自動取得しない。料金はユーザーのColab契約に依存し、本コードから課金サービスを購入しない。
- 初期ディスク空き20 GiB以上。証拠展開上限1.5 GiB、各累積ZIP上限768 MiB。16/32/48記事処理後に累積checkpointを作成・ダウンロード要求、64記事でFINAL。FINALだけで完全復元できる。途中分を含む転送総量の目安1.0〜1.5 GB。保存要求と手元での保存確認は区別。

## 3. 予想と判定

**H1：** block06のPC1–ノルム関連は、先頭点を外しても高く、低下は小さい。

- 支持：Aの区間下限≥0.80、かつBの区間下限≥−0.10。
- 反証：Aの区間上限<0.80、またはBの区間上限<−0.10。
- それ以外は不確定。必要な量が58記事未満ならデータ不足を優先する。

**H2：** 高ノルム上位6点の除外は、同数ランダム除外よりV1を実質的に下げる。

- 支持：Dの区間上限≤−0.05。
- 反証：Dの区間下限>−0.05。
- それ以外は不確定。Dが58記事未満ならデータ不足。

0.80・0.10・0.05はこの計画での実用上の定義であり、先行研究から確立した普遍的境界ではない。H2の反証には「差が0」だけでなく「低下はあるが5ポイント未満」も含む。H1/H2は同時に成立し得る。

判別に役立つ記述：位置0が最大ノルムか、上位6点に入るか、ノルム最大/中央値、PC1 eigengapを全記事で保存する。結果依存の層別を選抜条件や追加の主要検定にしない。PC1固有値が近接する場合、軸の不安定性を注意点として記す。
