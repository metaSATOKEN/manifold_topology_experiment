pr0012_download.py adapts the comm-based download and upload-generator pattern
of googlecolab/colabtools/google/colab/files.py (Apache-2.0), through this
project's preserved PR-0009 transport. Added serial queue, bounded archives,
browser acknowledgements, explicit resource release and streamed uploads.

Source: https://github.com/googlecolab/colabtools/blob/main/google/colab/files.py
No endorsement by Google is implied. A browser save request is not proof of
completed local-disk storage. PR-0012 browser behavior requires Colab testing.

P4 uses the serial queue and streaming-upload adapter from the user-provided pr0012_mixture_recovery_b50_fix1_one_cell.py, with namespace and size limits changed. Archive partitioning is newly implemented for P4. The original file is unchanged.
